# Project Charter: ÉTHERIA BOTANICALS Luxury Skincare Experience

## Project Overview
- **Project Name:** ÉTHERIA BOTANICALS
- **Tagline:** Cinematic Bio-Active Skincare & Cellular Botanical Elixirs
- **Objective:** Build a world-class, editorial luxury skincare ecommerce website featuring GSAP + ScrollTrigger parallax storytelling, fluid layered depth, interactive product discovery, and robust commerce capabilities.
- **Visual Reference:** Inspired by `ref-video/reference-video.mp4` (cinematic composition, multi-layer SVG curves, staggered parallax cards, rotating badge elements, elegant serif typography, smooth scroll choreography).

## Key Objectives & Success Criteria
1. **Cinematic Visual Experience:** Deliver an unforgettable editorial storytelling flow with 60 FPS GSAP ScrollTrigger transitions, parallax layering, pinned sections, and organic SVG motion.
2. **Commerce Integrity:** Completely isolate commerce state (cart, variants, prices, inventory, filtering) from animation timelines.
3. **Responsive Performance & Accessibility:** Full support for desktop, tablet, and mobile with lightened mobile keyframe paths, `prefers-reduced-motion` compliance, keyboard focus states, and semantic HTML5 layout.
4. **Zero Fabricated Evidence:** All product descriptions, clinical evidence labels, and ingredient profiles follow strict `EVIDENCE`, `INFERENCE`, `HYPOTHESIS`, and `DECISION` labeling.

## Scope & Deliverables
- **Production Artifacts:** Project Charter, Backlog, Risk Register, UX Requirements, Brand Strategy, UI Handoff, Commerce Architecture, Motion Spec, Performance Budget, Asset Manifest.
- **Production Web Application:** Vite-powered modern Web App with modular CSS/JS architecture.
- **Key Homepage Sections:**
  - Immersive Editorial Hero with Background Parallax & Floating Badge Button
  - Brand Ethos & Staggered Parallax Image Cards
  - Signature Product Reveal with Multi-Layered Depth
  - Ingredient & Texture Storytelling (Pinned Section)
  - Interactive Product Catalog with Quick View & Add-to-Cart Modal
  - Routine Discovery & Diagnostic Quiz Drawer
  - Clinical Trial & Proof Section
  - Customer Testimonials & Press Carousel
  - Interactive Cart Slide-over Drawer
  - Premium Editorial Footer with Newsletter Signup

## Team Roles & Ownership
- **@pm:** Project scope, backlog, risk tracking, acceptance gates.
- **@ux:** Information architecture, user needs, conversion flow.
- **@brand:** Naming, verbal identity, color palette, visual storytelling guidelines.
- **@ui:** Wireframes, grid system, typography scale, component design.
- **@commerce:** Catalog schema, cart state management, variant matrix, checkout simulation.
- **@parallax / @frontend:** GSAP + ScrollTrigger choreography, smooth parallax layers, reduced-motion fallbacks, production build.
- **@qa:** Performance budget validation, browser testing, accessibility check, build verification.
