# Skill: UI / Product Design for Skincare Commerce

## Objective
Create the responsive UI specification for a premium skincare ecommerce site whose visual experience is inspired by the supplied video while preserving usability and conversion.

## Inputs
- `production_artifacts/01_research/UX_Requirements.md`
- `production_artifacts/02_brand/Brand_Strategy.md`
- `production_artifacts/04_commerce/Commerce_Architecture.md` when available
- supplied video/reference imagery

## Design requirements
Define:
- sitemap and navigation
- homepage sections
- collection/product listing experience
- product detail page
- cart/checkout states
- responsive behavior
- design tokens
- typography
- color system
- buttons, forms and controls
- cards and product modules
- trust/proof modules
- skincare education/ingredient modules
- empty/error/loading states
- accessibility requirements
- motion annotations

## Reference-video direction
Translate the reference into design principles rather than copying it:
- strong hero composition
- layered editorial imagery
- large typography
- product-focused focal points
- generous negative space
- scroll-led transitions
- depth created through layered movement
- clear transition from storytelling to shopping

Every decorative animation must have a non-animated equivalent.

## Deliverable
Write:
`production_artifacts/03_ux_ui/UI_Handoff.md`

Include component behavior, breakpoints, content hierarchy, states and motion annotations.

## Constraint
Do not invent commerce behavior that contradicts the commerce architecture.
